# 문자열 덧셈 계산기

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

## 기능 요구 사항

- 쉼표 또는 콜론을 기본 구분자로 사용한다.
- 문자열 앞에 커스텀 구분자를 지정하여 사용 가능하다.
- 빈 문자열은 0을 반환한다.
- 사용자가 잘못된 값을 입력 시 `IllegalArgumentException` 발생 후 애플리케이션 종료

### 입출력 요구 사항

- 입력되는 문자열은 구분자와 양수로 구성된다.
- 덧셈 결과 출력 형식
  ```
  결과 : 6
  ```
- 실행 결과 예시
  ```
  덧셈할 문자열을 입력해 주세요.
  1,2:3
  결과 : 6
  ```

## 기능 목록

### 1. 입력

- [ ] 문자열 입력 받기
- [ ] 빈 문자열 -> 0 반환
- [ ] `null` -> 예외 발생

### 2. 구분자 처리

- [ ] 기본 구분자: `,` 또는 `:`
- [ ] 커스텀 구분자: //<구분자>\n 형식
    - [ ] 커스텀 구분자가 2자 이상이면 예외 발생
- [ ] 특수문자 처리
- [ ] 구분자를 기준으로 숫자 분리

### 3. 숫자 처리

- [ ] 숫자가 아닌 값 존재 시 예외 발생
- [ ] 음수 또는 0 존재 시 예외 발생
- [ ] 숫자 타입 `double`

### 4. 양수 합산

- [ ] 모든 숫자 합하기
- [ ] 숫자가 없을 경우 0 반환

### 5. 출력

- [ ] 결과 출력
- [ ] 계산 결과가 소수점 이하 0일 경우 정수 형태로 출력

### 예외 발생 케이스

| 입력 값              | 설명          | 처리 결과                       |
|-------------------|-------------|-----------------------------|
| `null`            | 입력이 null    | IllegalArgumentException 발생 |
| `"1,2,a"`         | 숫자가 아닌 값 포함 | IllegalArgumentException 발생 |
| `"//!!\n1!!2!!3"` | 다문자 구분자 사용  | IllegalArgumentException 발생 |
| `"1,-2,3"`        | 음수 포함       | IllegalArgumentException 발생 |
| `"1,0,3"`         | 0 포함        | IllegalArgumentException 발생 |

## 클래스 설계

- **Application**: 실행 시작점. 입력을 받아 Controller에 전달
- **InputView**: 사용자 입력 처리 (null, 빈 문자열 체크)
- **OutputView**: 결과 출력 담당
- **Controller**: 전체 실행 흐름 제어 (파싱 → 변환 → 계산 → 출력)
- **Parser**: 입력 문자열을 숫자 문자열 배열로 분리 (커스텀/기본 구분자 처리)
- **NumberConverter**: 문자열 배열을 숫자 리스트로 변환
- **Numbers**: 숫자 리스트 저장 및 검증, 합산 수행
- **Delimiter**: 구분자 로직 담당 (커스텀 구분자 추출 및 유효성 검사)
