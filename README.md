# 문자열 덧셈 계산기

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

## 기능 요구 사항

- 쉼표 또는 콜론을 기본 구분자로 사용한다.
- 문자열 앞에 커스텀 구분자를 지정하여 사용 가능하다.
- 빈 문자열은 0을 반환한다.
- 사용자가 잘못된 값을 입력 시 `IllegalArgumentException` 발생 후 애플리케이션 종료

### 입출력 요구 사항

- 입력되는 문자열은 구분자와 양수로 구성된다.
- 덧셈 결과 출력 형식
  ```
  결과 : 6
  ```
- 실행 결과 예시
  ```
  덧셈할 문자열을 입력해 주세요.
  1,2:3
  결과 : 6
  ```

## 기능 목록

### 1. 입력

- [ ] 문자열 입력 받기
- [ ] 빈 문자열 -> 0 반환
- [ ] `null` -> 예외 발생

### 2. 구분자 처리

- [ ] 기본 구분자: `,` 또는 `:`
- [ ] 커스텀 구분자: //<구분자>\n 형식
    - [ ] 커스텀 구분자가 2자 이상이면 예외 발생
- [ ] 구분자를 기준으로 숫자 분리

### 3. 숫자 처리

- [ ] 숫자가 아닌 값 존재 시 예외 발생
- [ ] 음수 또는 0 존재 시 예외 발생
- [ ] `int` 범위 벗어날 수 있으므로 `long` 타입 사용

### 4. 양수 합산

- [ ] 모든 숫자 합하기
- [ ] 숫자가 없을 경우 0 반환

### 5. 출력

- [ ] 결과 출력 (정수)

### 예외 발생 케이스

| 입력 값              | 설명          | 처리 결과                       |
|-------------------|-------------|-----------------------------|
| `null`            | 입력이 null    | IllegalArgumentException 발생 |
| `"1,2,a"`         | 숫자가 아닌 값 포함 | IllegalArgumentException 발생 |
| `"//!!\n1!!2!!3"` | 다문자 구분자 사용  | IllegalArgumentException 발생 |
| `"1,-2,3"`        | 음수 포함       | IllegalArgumentException 발생 |
| `"1,0,3"`         | 0 포함        | IllegalArgumentException 발생 |

---

## 클래스 설계

- **InputView**: 사용자 입력 담당. null, 빈 문자열 체크
- **Parser**: 문자열을 구분자로 분리, 각 요소를 숫자(long)로 변환
- **Validator**: 변환된 숫자 리스트에 대한 유효성 검사
- **Calculator**: 숫자 리스트 합산
- **OutputView**: 결과 출력
- **Application**: 전체 흐름 제어
